# Keen Agency — Digital Creative & Kinetic Growth Platform

A modern, high-performance website for **Keen Agency** built with Next.js 16 (App Router), Tailwind CSS v4, Framer Motion, and GSAP. Featuring a **Cinematic Swiss Bento Grid** design system, full bilingual support (English & French), interactive modals, and the official transparent Keen Agency branding.

---

## ✦ Key Features

- **Cinematic Swiss Bento Architecture**: Modular layouts with technical spec monitors, live counters, and glassmorphism.
- **Full-Bleed Parallax Hero**: Atmospheric contrast vignette, GSAP load sequences, and responsive action triggers.
- **Bilingual Engine (EN / FR)**: Instant language toggle with persistent user preference and dynamic metadata.
- **5 Core Capability Modules**:
  - `MOD.01 // Branding & Design`
  - `MOD.02 // Digital Marketing & Data`
  - `MOD.03 // Content Creation & 4K Video`
  - `MOD.04 // Web Design & Development`
  - `MOD.05 // Strategy & Consulting`
- **6-Phase Execution Pipeline**: Interactive step-by-step collaborative methodology.
- **Official Brand Assets**: Clean transparent logo variants for both light mode and dark mode sections.
- **Interactive Modals**: 60 FPS simulated Showreel player, Case Study inspector, and brief submission with confetti animations.
- **Direct WhatsApp & 24/7 Support**: Quick connect buttons linked to official agency channels.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router, Turbopack)
- **Styling**: Tailwind CSS v4, Vanilla CSS Design Tokens
- **Typography**: Poppins (Google Fonts)
- **Animations**: Framer Motion & GSAP (ScrollTrigger)
- **Icons**: Lucide React
- **FX**: Canvas Confetti

---

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/mediani-mehdi/Keen-Agency.git

# Navigate into directory
cd Keen-Agency

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
